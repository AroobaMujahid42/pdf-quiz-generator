# QuizCraft AI

Upload a PDF or Word document and get an AI-generated quiz (multiple choice + short answer),
which you can download as Word or PDF. Built with Streamlit and Groq.

## Setup

1. Create a virtual environment and install dependencies:
   `pip install -r requirements.txt`
2. Copy `.env.example` to `.env` and add your free Groq API key from https://console.groq.com
3. Run the app: `streamlit run app.py`
